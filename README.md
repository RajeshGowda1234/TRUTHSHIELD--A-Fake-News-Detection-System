# TRUTHSHIELD

## Fake News Detection System using ML and NLP

TruthShield is a fake news detection system designed to identify misinformation using Machine Learning and Natural Language Processing.

## Modules
- Frontend: Web interface for user interaction
- Backend: API for fake news prediction
- Chrome Extension: Real-time news verification

## Technologies Used
- Python, Flask
- Machine Learning, NLP
- React.js
- Chrome Extension

## Focus Areas
- AI-based content verification
- Misinformation detection
- Security and ethical AI practices
